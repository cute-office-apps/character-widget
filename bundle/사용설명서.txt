캐릭터 위젯 사용 설명서
======================

바탕화면 위에 내가 고른 그림이 캐릭터로 떠 있어요.
- 캐릭터를 클릭하면 메모가 열려요 (윈도우 스티커 메모 연동)
- 구글 캘린더를 연결하면 오늘 일정과 일정 10분 전을 말풍선으로 알려줘요
- 계절 테마(봄·여름·가을·겨울·크리스마스)로 꾸밀 수 있어요


1. 설치
----------------------------------------
(이 '파이썬 포함판' 은 Python 을 따로 설치하지 않아도 돼요.)

(1) 받은 zip 파일을 우클릭 → "압축 풀기"   ※ 꼭 먼저 압축을 풀어 주세요
(2) 풀린 폴더 안의 "설치하기" 를 더블클릭
    (파랑·노랑 뱀 모양 아이콘이에요. 공식 Python 프로그램이라 이 모양이에요.)
(3) [설치하기] → [지금 실행하기]
    → 바탕화면에 "캐릭터 위젯" 바로가기가 생겨요. 다음부터는 이걸 누르면 돼요.

※ 폴더 안의 다른 파일(.dll, runtime 폴더 등)은 위젯이 쓰는 부품이에요. 건드리지 않아도 돼요.
※ 설치가 끝나면 압축 푼 폴더와 zip 파일은 지워도 돼요.


2. 처음 사용하기
----------------------------------------
(1) 바탕화면에 점선 네모 "캐릭터를 등록해 주세요!" 가 나와요
(2) 네모를 클릭 → 캐릭터로 쓸 그림 고르기 → 이름 짓기
(3) 캐릭터가 말풍선으로 사용법을 알려줘요

그림 팁
- 배경이 투명한 PNG 가 제일 예뻐요. 움직이는 GIF 도 돼요.
- 흰 배경·체크무늬 배경은 자동으로 지워줘요.
- JPG·BMP·TIFF 도 돼요 (PNG 로 바꿔서 저장하고, 사진 방향도 바로잡아요)
- HEIC(아이폰 사진)·WebP·AVIF 는 Microsoft Store 의 "HEIF 이미지 확장", "WebP 이미지 확장",
  "AV1 비디오 확장"이 있어야 열려요
- 배경을 지우고 싶으면 → 윈도우 11 그림판에서 열기 → "배경 제거" → 다른 이름으로 저장 → PNG


3. 사용법
----------------------------------------
- 클릭        : 메모 열기
- 드래그      : 위치 옮기기
- 우클릭      : 메뉴 (메모 / 오늘 일정 / 꾸미기 / 캐릭터 바꾸기 / 설정 / 사용법 보기 /
                캐릭터 랜덤으로 바꾸기 / 자동 실행 / 다시 시작 / 끄기)
- 캐릭터 랜덤으로 바꾸기: 켜두면 켤 때마다, 그리고 30분마다 다른 캐릭터로 바뀌어요
                (캐릭터가 2개 이상 있어야 해요. 간격은 settings.ini 의 RANDOM_MINUTES)
- 지금 바로 바꾸기: 메뉴의 ↻ 버튼 (메뉴를 연 채로 F5 키도 돼요). 스위치를 꺼둬도 쓸 수 있어요
- 말풍선 클릭 : 말풍선 닫기


4. 구글 캘린더 연결 (선택)
----------------------------------------
(1) PC 에서 calendar.google.com → 오른쪽 위 톱니바퀴 → 설정
(2) 왼쪽 "내 캘린더의 설정" 에서 내 이름 클릭
(3) 맨 아래 "캘린더 통합" → "iCal 형식의 비공개 주소" 복사
      ✔ …/private-…/basic.ics   (이 주소를 써야 해요)
      ✖ …/public/basic.ics        (공개 주소 - 안 돼요)
      ✖ …/calendar/u/0/r          (웹페이지 주소 - 안 돼요)
(4) 캐릭터 우클릭 → 설정 → 구글 캘린더 칸에 붙여넣기 → [연결 확인] → [저장]

- 갤럭시 캘린더를 쓰면: 일정 저장할 캘린더를 "구글 계정" 으로 골라야 위젯에 나와요.
- "할 일" 은 일정이 아니라서 나오지 않아요.


5. 꾸미기
----------------------------------------
캐릭터 우클릭 → 꾸미기
- 위쪽 탭에서 테마를 고르고, 소품을 누르면 입고 다시 누르면 벗어요
- "이 테마 한 번에 입히기" 로 세트를 통째로 입혀요 (벚꽃잎·물방울·낙엽·눈 날리기 포함)
- 미리보기에서 드래그로 위치, 크게/작게·↺↻ 로 크기와 기울기 조절
- 자동 꾸미기: 크리스마스만 / 계절마다 고를 수 있어요


6. 업데이트 / 제거
----------------------------------------
- 자동 업데이트: 새 버전이 나오면 캐릭터가 말풍선으로 알려줘요 → [업데이트] 한 번이면 끝
  (내 메모·캐릭터·설정은 그대로예요. 설정 창의 "업데이트 확인"으로 직접 확인할 수도 있어요)
- 직접 업데이트: 새 zip 을 받아 압축 풀고 "설치하기" → [업데이트하기]
            (내 메모·캐릭터·설정은 그대로 남아요)
- 제거: "설치하기" → [제거하기]


7. 문제가 생기면
----------------------------------------
- 바로가기를 눌러도 아무것도 안 뜰 때:
    Windows 키 + R → %LOCALAPPDATA%\CharacterWidget 입력 → 확인
    → 열린 폴더의 error.log, launch.log 내용을 알려주세요
- "이미 켜져 있어요" 가 뜨는데 화면에 없을 때:
    Ctrl+Shift+Esc → Python(pythonw) 작업 끝내기 → 다시 실행
- 오류 기록: 캐릭터 우클릭 → 설정 → "위젯 폴더 열기" → error.log


안내
----------------------------------------
- 이 위젯은 설정에 넣은 구글 캘린더 주소에서 일정을 "읽기"만 해요. 다른 곳으로 보내는 정보는 없어요.
- 캘린더 비공개 주소는 비밀번호와 같아요. 다른 사람에게 보내지 마세요.
- 다른 사람이 그린 그림이나 캐릭터는 개인적으로만 쓰고, 다시 퍼뜨리지 마세요.
